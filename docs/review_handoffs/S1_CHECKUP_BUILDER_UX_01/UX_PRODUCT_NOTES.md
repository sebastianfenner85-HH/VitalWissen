# UX Product Notes — S1-CHECKUP-BUILDER-UX-01

## Problem vorher

Der Checkup-Builder konnte Panel- und Themenwerte sammeln, aber der Unterschied zwischen Blutbild und zusätzlichem Gesprächswert war noch nicht klar genug. Besonders das große Blutbild kann leicht als vollständiger Gesundheitscheck missverstanden werden.

## Lösung jetzt

### Panel-Erklärung

Bei Auswahl eines Panels wird erklärt, was das Blutbild abbildet. Zusätzlich wird explizit sichtbar, welche häufig besprochenen Werte nicht enthalten sind.

### Vier Ergebnisgruppen

Die Ergebnisliste wird nach Nutzungskontext gruppiert:

1. Im gewählten Blutbild enthalten
2. Nicht Teil des großen Blutbilds
3. Zusätzlich ausgewählte Themenwerte
4. Nur nach fachlicher Einordnung

### Gesprächsliste

Unter der Ergebnisliste entsteht ein kopierbarer Textblock für das Gespräch mit einer Fachperson. Er enthält Panel, Themen, gruppierte Werte und den Sicherheitsrahmen.

### Copy und Print

Die Liste kann kopiert oder über die Browser-Druckfunktion als PDF gespeichert werden.

### Leerer Zustand

Ohne Auswahl wird kein deaktivierter Hauptbutton gezeigt, sondern ein erklärender Hinweis.

## Folgepunkte

- Visueller Preview-Test auf Mobile.
- Copy-Button in Browser testen.
- Print-Ansicht kurz prüfen.
